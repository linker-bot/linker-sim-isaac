# 实时状态流使用说明

本文说明单臂、双臂交互 runtime 的实时状态流如何开启，以及输出数据如何理解。

## 能力边界

实时状态流用于观测，不接收运动命令。命令仍通过 stdin JSONL、TCP JSONL 或 WebSocket JSON 发送。

支持：

- Foxglove live server。
- Foxglove MCAP 离线记录。
- `/joint_states` 标准关节状态。
- `/scene` 对象 marker。
- `/linkerbot/state` JSON 完整状态快照。
- 可选 commanded、measured、applied 三类 effort。
- 可选 env runtime object root pose。

不支持：

- 通过 Foxglove 发送 motion command。
- 将交互 WebSocket/TCP 端口与 Foxglove live 端口复用。
- 由后台线程直接读取 Isaac articulation、PhysX view 或 USD stage。

## 启动方式

单臂状态流建议使用端口 `8765`：

```bash
PYTHONPATH=src python scripts/single_arm_interactive.py \
  --env scene1 \
  --gui \
  --foxglove-live-port 8765 \
  --state-include-objects
```

双臂状态流建议使用端口 `8766`：

```bash
PYTHONPATH=src python scripts/dual_arm_interactive.py \
  --gui --hold \
  --foxglove-live-host 127.0.0.1 \
  --foxglove-live-port 8766 \
  --state-rate-hz 60 \
  --state-include-objects
```

同时写 MCAP：

```bash
PYTHONPATH=src python scripts/dual_arm_interactive.py \
  --gui --hold \
  --foxglove-mcap-path logs/interactive_state.mcap \
  --state-rate-hz 60 \
  --state-include-objects \
  --state-include-efforts \
  --foxglove-joint-effort-field measured
```

## CLI 参数

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `--state-rate-hz` | `60.0` | 状态采样频率；`<=0` 时关闭状态流。只有设置 live port 或 MCAP path 时才会真正启动。 |
| `--state-include-objects` | 关闭 | 采样 env runtime object root pose，并发布到 `/linkerbot/state` 和 `/scene`。 |
| `--state-include-efforts` | 关闭 | 读取 commanded、measured、applied 三类 effort。不可用时填 `nan` 或 `null`。 |
| `--foxglove-live-host` | `127.0.0.1` | Foxglove live server 监听地址。 |
| `--foxglove-live-port` | 无 | 状态流 live server 监听端口；不传则不开 live。 |
| `--foxglove-mcap-path` | 无 | 状态流 MCAP 输出路径；不传则不写 MCAP。 |
| `--foxglove-joint-effort-field` | `none` | 写入 `/joint_states` 标准 `effort` 字段的 effort 语义，可选 `none`、`commanded`、`measured`、`applied`。 |

## Topic

| topic | 编码 | 用途 |
| --- | --- | --- |
| `/joint_states` | Foxglove `JointStates` protobuf | 曲线面板和关节状态面板使用。 |
| `/scene` | Foxglove `SceneUpdate` protobuf | 3D 面板显示对象 marker。 |
| `/linkerbot/state` | JSON | 完整状态快照，包含 step/time、机器人状态、effort、对象 pose 和 phase。 |

完整 topic、MCAP、相机图像和排错说明见 [Foxglove 数据使用说明](../传感器与遥测/Foxglove%20数据使用说明.md)。

## Effort 字段

三类 effort 不应混用：

- `commanded_efforts`：项目控制器在 Python 侧希望下发的 effort。
- `measured_efforts`：PhysX 求解器测得或计算的 generalized force。
- `applied_efforts`：Isaac articulation 当前记录的 actuator/drive effort。

Foxglove 标准 `JointStates` 只有一个 `effort` 字段，所以 `/joint_states` 只能选择其中一种语义。需要完整数据时读取 `/linkerbot/state`。
